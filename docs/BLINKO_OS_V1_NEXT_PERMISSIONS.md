# Próxima frente — Usuários, papéis e permissões

Após o fechamento de Indicadores/Metas na Simulação 011, o próximo item explícito do roadmap oficial é **Usuários, papéis e permissões**.

O handoff define que o login único por ambiente é suficiente apenas para a fase atual e não para operação madura.

Diretrizes da próxima implementação:

- usuário individual;
- papéis internos;
- menor privilégio;
- auditoria associada ao usuário real;
- proteção específica para financeiro e contratos;
- não fingir revisão em quatro olhos quando a operação tiver uma única pessoa;
- acesso externo/cliente somente quando houver necessidade real;
- migração e testes somente em `blinko-os-v1-sim` antes de qualquer promoção.

Esta nota é apenas um marcador de continuidade. Nenhuma permissão nova foi promovida para produção/main neste checkpoint.
